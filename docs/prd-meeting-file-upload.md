# PRD: Загрузка файлов встречи

**Дата**: 2026-11-02
**Статус**: Draft

## Цель

Дать владельцу встречи возможность прикреплять к ней файлы (записи, документы, презентации и др.), чтобы они хранились вместе со встречей и были доступны для последующей обработки. Пользователь видит все материалы встречи и статус каждого файла на странице встречи.

## Пользовательские сценарии

- Пользователь открывает страницу своей встречи и выбирает файл (через кнопку или drag-and-drop) -> файл загружается, в списке появляется запись со статусом «Загружается», затем «Загружен».
- Пользователь выбирает несколько файлов за раз -> каждый загружается отдельно, у каждого свой прогресс и статус.
- Пользователь пытается загрузить файл больше 500 МБ -> загрузка отклоняется, показывается понятное сообщение о превышении лимита.
- Загрузка файла завершилась ошибкой (обрыв сети, ошибка сервера) -> у файла статус «Ошибка», доступна повторная загрузка.
- Пользователь открывает страницу встречи -> видит список прикреплённых файлов: имя, размер, дата загрузки, статус.
- Пользователь скачивает файл из списка -> получает исходный файл с исходным именем.
- Пользователь удаляет файл из списка -> файл исчезает из списка и удаляется из хранилища.
- Другой авторизованный пользователь обращается к файлам чужой встречи -> получает отказ (404).

## В скоупе

- Загрузка файлов любого типа к существующей встрече; несколько файлов на встречу.
- Максимальный размер одного файла — 500 МБ.
- Хранение файлов на локальном диске сервера; метаданные (имя, размер, MIME-тип, дата, статус, встреча) — в БД.
- Статусы файла: `uploading`, `uploaded`, `failed`. Статус хранится и отдаётся API; сама обработка не выполняется.
- API: загрузка файла, список файлов встречи, скачивание файла, удаление файла. Только для авторизованных; доступ только у владельца встречи.
- UI на странице встречи: зона загрузки (выбор файла и drag-and-drop), индикатор прогресса, список файлов со статусами, скачивание и удаление.
- Описание новых эндпоинтов в Swagger.
- Unit- и e2e-тесты API, тесты UI.
- Обновление документации (`CLAUDE.md`, `apps/api/CLAUDE.md`, `.env.example`) в рамках изменения.

## Не в скоупе

- Какая-либо обработка файлов: транскрибация, саммари, транскодирование, превью.
- Встроенный плеер и предпросмотр содержимого файлов.
- Доступ к файлам для участников встречи, кроме владельца; публичные ссылки.
- Облачное/S3-хранилище.
- Возобновляемая (chunked) загрузка.
- Антивирусная проверка, квоты на пользователя.
- Переименование файлов и перенос между встречами.

## Технические ограничения

- Лимит 500 МБ на файл проверяется и на клиенте, и на сервере; сервер не должен загружать файл целиком в память.
- Web проксирует запросы на API через route handlers Next.js; прокси должен пропускать тела до 500 МБ без буферизации в памяти. JWT остаётся в HttpOnly-cookie.
- Файлы на диске хранятся под сгенерированными именами, а не под пользовательскими; исходное имя — только в БД (защита от path traversal).
- Каталог хранения настраивается через переменную окружения с дефолтом; путь вне git.
- API — нативный ESM, CQRS (команды/запросы через шины), валидация и Swagger по существующим соглашениям проекта.
- Миграции Prisma 7; e2e-тесты используют реальную БД.
- При удалении встречи или файла физический файл не должен оставаться на диске.

## Критерии готовности

- [ ] Владелец встречи может загрузить файл любого типа размером до 500 МБ, файл виден в списке встречи со статусом `uploaded`.
- [ ] Можно загрузить несколько файлов в одну встречу; у каждого свой прогресс и статус.
- [ ] Файл больше 500 МБ отклоняется API (код 413) и UI до отправки с понятным сообщением.
- [ ] При ошибке загрузки файл получает статус `failed`, в UI есть повторная попытка; незавершённые файлы не остаются на диске.
- [ ] Список файлов показывает имя, размер, дату загрузки и статус.
- [ ] Скачанный файл побайтно совпадает с загруженным и имеет исходное имя.
- [ ] Удаление файла убирает запись из БД и файл с диска.
- [ ] Запросы без токена получают 401; запросы к файлам чужой встречи — 404; это покрыто e2e-тестами.
- [ ] Загрузка файла в 500 МБ не приводит к росту памяти процесса API на размер файла.
- [ ] Эндпоинты описаны в Swagger (`/docs`).
- [ ] `pnpm lint`, `pnpm test` и `pnpm test:e2e` проходят.
- [ ] Документация (`CLAUDE.md`, `apps/api/CLAUDE.md`, `.env.example`) обновлена.
